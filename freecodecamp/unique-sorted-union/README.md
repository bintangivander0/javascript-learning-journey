# Unique Sorted Union

Program ini digunakan untuk menggabungkan beberapa array menjadi satu array baru tanpa nilai yang duplikat.

Urutan nilai tetap mengikuti urutan pertama kali nilai tersebut ditemukan.

## Yang Saya Pelajari

- Rest parameter `...arrs`
- Nested `for` loop
- `indexOf()`
- `push()`
- `return`
- Mengecek dan menghindari data duplikat
