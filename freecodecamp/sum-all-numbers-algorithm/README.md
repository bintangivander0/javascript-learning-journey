# Sum All Numbers Algorithm

Program ini digunakan untuk menghitung jumlah total dari seluruh deret angka di antara dua angka yang diberikan dalam sebuah array, termasuk kedua angka tersebut.

Program dapat menghitung:
* Angka berurutan dari kecil ke besar.
* Angka acak (posisi angka besar di depan atau sebaliknya).
* Angka bernilai negatif.

## Yang Saya Pelajari

* Function dengan parameter array.
* Spread operator `...` untuk mengurai elemen array.
* `Math.min()` untuk mencari nilai terkecil.
* `Math.max()` untuk mencari nilai terbesar.
* `for loop` untuk membuat deret angka.
* Operator penambahan `+=` untuk menjumlahkan nilai.
* Mengembalikan nilai menggunakan `return`.

## Parameter arr

Parameter `arr` digunakan untuk memasukkan dua angka sebagai batas awal dan batas akhir perhitungan.

Contoh:

```javascript
sumAll([1, 4]);
```

Hasil: `10` *(Penjelasan: 1 + 2 + 3 + 4 = 10)*
