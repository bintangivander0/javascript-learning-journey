# Apa itu API dan Web API?

Mari kita belajar tentang API dan mengapa hal ini sangat penting dalam pembuatan website. 

API adalah singkatan dari **Application Programming Interface** (Antarmuka Pemrograman Aplikasi). Sederhananya, API adalah sebuah jembatan atau aturan yang sistemnya membantu satu aplikasi untuk mengobrol dan bertukar data dengan aplikasi lainnya secara mudah.

Kamu bisa membayangkan API seperti balok mainan (lego). Sebagai developer, kamu tidak perlu membuat fungsi yang rumit dari nol. Kamu tinggal memakai balok-balok yang sudah jadi untuk menyusun aplikasi yang lebih canggih.

## Jenis-Jenis Web API

Ada banyak jenis API di dunia digital. Namun, API yang khusus dibuat untuk aplikasi website disebut **Web API**. Perlu diingat, Web API ini aslinya **bukan** bagian dari bahasa pemrograman JavaScript itu sendiri.

Web API untuk website biasanya dibagi menjadi dua kelompok besar:

### 1. Browser API (API Bawaan Browser)
Browser API adalah fitur penjelajah internet (seperti Google Chrome atau Mozilla Firefox) yang bisa kita pakai menggunakan JavaScript. Fitur ini berguna untuk mengatur tampilan website, membaca ketikan user, menyimpan data, atau terhubung ke internet.

Contoh Browser API yang paling sering dipakai:
* **DOM API**: Digunakan untuk mengubah isi, gaya (CSS), dan elemen HTML pada halaman website.
* **Storage API**: Digunakan untuk menyimpan data secara lokal langsung di dalam perangkat atau HP milik pengguna website.
* **Geolocation API**: Digunakan untuk mengetahui lokasi pengguna saat ini (setelah mendapat izin).
* **Media API**: Digunakan untuk memutar video atau audio di halaman web.

Karena sudah bawaan, kamu tidak perlu mengunduh apa pun untuk menggunakan Browser API. Semuanya sudah siap pakai di dalam browser.

### 2. Third-Party API (API Pihak Ketiga)
API jenis ini tidak disediakan oleh browser. API ini dibuat oleh perusahaan atau orang lain. Untuk menggunakannya, kita harus menghubungkan kode aplikasi kita ke server mereka. Biasanya, mereka menyediakan buku panduan (dokumentasi) tentang cara pakainya.

Contoh Third-Party API yang populer:
* **Google Maps API**: Untuk menampilkan peta interaktif di dalam websitemu.
* **API Cuaca**: Untuk menampilkan ramalan cuaca hari ini.
* **API Media Sosial**: Untuk memunculkan tombol *share* ke Instagram atau login menggunakan akun Google.
* **API Pembayaran**: Untuk menerima pembayaran *online* lewat bank atau e-wallet.

## Kesimpulan

Web API adalah alat bantu yang sangat penting untuk membuat website modern. Dengan memanfaatkan API, websitemu bisa terhubung ke berbagai layanan dan data di internet, sehingga websitemu menjadi lebih interaktif dan keren.
