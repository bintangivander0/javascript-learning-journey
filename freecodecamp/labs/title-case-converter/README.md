# Build a Title Case Converter

Yang saya pelajari:

- `split(" ")` memecah kalimat menjadi array kata
- `for` membaca setiap kata
- `charAt(0)` mengambil karakter pertama
- `toUpperCase()` mengubah huruf pertama
- `slice(1)` mengambil sisa kata
- `push()` memasukkan hasil
- `join(" ")` menyatukan array kembali menjadi string
