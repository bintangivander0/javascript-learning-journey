# Password Generator

Program ini digunakan untuk membuat password acak dengan panjang yang ditentukan.

Password dapat berisi:

- Huruf besar
- Huruf kecil
- Angka
- Simbol

## Yang Saya Pelajari

- Function dengan parameter
- `for` loop
- `Math.random()`
- `Math.floor()`
- `.length`
- Mengambil karakter dari string berdasarkan index
- Menambahkan karakter ke string dengan `+=`
- `return`
- Template literal

## Parameter `passLength`

Parameter `passLength` digunakan untuk menentukan panjang password yang ingin dibuat.

Contoh:

```js
generatePassword(12);
```
Hasil: 
`Generated password: 0m9ulmsC*Fqe`
