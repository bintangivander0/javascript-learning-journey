# Software Engineering Learning Journey

A record of my journey from an Electrical Engineering background toward becoming a Software Engineer.

I started exploring programming through web development and gradually became interested in building software, solving problems, understanding systems, and learning how different technologies work together.

This repository documents that process through hands-on exercises, projects, experiments, and learning notes.

---

## About This Journey

My academic background is in **Electrical Engineering**, with a focus on high-voltage engineering.

While continuing my studies, I started learning software development independently and became increasingly interested in programming and software engineering.

This repository is where I document that transition.

I am not trying to learn everything at once.

The focus is to build a solid foundation, practice consistently, create real projects, and gradually move toward more advanced software engineering concepts.

## Learning Process

I try to approach each topic through practice rather than only following tutorials.

```text
Learn
  ↓
Understand
  ↓
Build
  ↓
Test
  ↓
Break
  ↓
Debug
  ↓
Document
  ↓
Repeat
```

The goal is not simply to finish a course.

The goal is to understand what I am building and become better at solving problems independently.
